05 / FAQ

Answers for creative founders.

How does client access work without forcing them to register?

Clients receive a clean, branded link where they can immediately review assigned deliverables, submit structured feedback, and sign off with their name.

How does the revision allowance engine prevent scope creep?

When you create a project, you set a revision allowance (e.g. 2 or 3 revisions). Every client change request is tracked and validated against this quota. If a client attempts to submit beyond the quota, Python halts the request.

How are PDF invoices generated?

CreativeFlow utilizes a Python ReportLab backend to generate vector-crisp, professional PDF invoices directly from your project milestone data with decimal-precise balance tracking.
